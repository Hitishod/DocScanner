How to install

Docverse is not on the Play Store, so you install the file yourself. It takes a minute.

  1. Download the APK with the button above, using your phone.
  2. Open the file from your notifications or the Downloads folder.
  3. If Android says it can't install from this source, tap Settings and turn on Allow from this source, then go back.
  4. Tap Install. If Play Protect shows a warning, tap More details, then Install anyway.
  5. Open Docverse and tap Scan.

Questions

Is it really free?

Yes. There are no ads, no subscription and no account.

Why does Android show a warning?

Android warns about every app installed from outside the Play Store. This is normal for apps shared as an APK file.

Does it need the internet?

Scanning, editing, conversion and text recognition run on your phone. The first time you use the scanner or text recognition, Google Play services may download a small component, so an internet connection helps once.

Which phones does it work on?

Android 7.0 or newer with Google Play services. It is not meant for devices without Google services, such as Amazon Fire tablets.

Where are my scans stored?

Only inside the app on your phone. You choose when to share or save a copy to Downloads. See the privacy page.
